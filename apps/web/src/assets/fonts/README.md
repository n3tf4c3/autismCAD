# Fontes da exportacao PDF

Noto Sans Regular e Bold, projeto Google Noto, sob SIL Open Font License 1.1
(arquivo `OFL.txt`). Fontes obtidas de `googlefonts/noto-fonts`, caminho
`hinted/ttf/NotoSans/`. Sao assets locais; a exportacao nao consulta provedores externos.

Os PDFs normalizam caracteres combinados para NFC. Caracteres sem glifo sao
representados por `[U+XXXX]` e explicados no proprio PDF; o dado armazenado nao muda.
